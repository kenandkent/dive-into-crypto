# 本地开发环境部署

> 适用分支：`short-meme`。本文所有命令均已在本机（macOS，Python 3.13 + uv 0.7.6 + Node 24）实地验证通过。
> 应用本体是**单机桌面程序**：本机 FastAPI（默认 `127.0.0.1:46408`）+ 同进程服务的 React 页面，无外部服务端依赖。

## 1. 前置要求

| 依赖 | 版本要求 | 检查命令 |
|---|---|---|
| Python | ≥ 3.12 | `python3 --version` |
| uv | 任意近期版本 | `uv --version` |
| Node | ≥ 18 | `node --version` |
| git | 任意 | `git --version` |

网络要求：需能访问 Binance 公网（`fapi.binance.com`、`api.binance.com`）。部分地区 Binance 期货数据有 451 地域限制——这是网络条件不是 bug，UI 会明确提示数据不可用。

## 2. 获取代码

```bash
git clone <repo-url> short-lab && cd short-lab
git checkout short-meme
git rev-parse HEAD && git status --short   # 记录基线
```

## 3. 后端部署

```bash
cd desktop/backend
uv sync                  # 在线：安装 backend + Crypcodile（pinned commit）
```

**本机实测情况**：直连 PyPI 出现 TLS 阻断时，用离线模式走本地缓存：

```bash
uv sync --offline
```

若缓存也不完整，直接使用仓库自带的 `.venv`（依赖已齐：fastapi / duckdb / pandas / Crypcodile 均可导入）：

```bash
.venv/bin/python -c "import fastapi, duckdb, pandas; print('deps ok')"
```

### 验证后端

```bash
cd desktop/backend
uv run --offline pytest -q        # 离线全量；本机实测 890 passed, 6 deselected
uv run pytest -m live -q          # 需公网：打真实 Binance，CI 默认不跑
```

> 若 `uv run` 因锁文件重解析失败（离线无元数据），等价命令：`.venv/bin/python -m pytest -q`

## 4. 前端部署

UI 以预构建包形式随后端一起服务，**运行不需要 Node**；只有改前端代码才需要：

```bash
cd desktop/ui
npm install                # 本机 node_modules 已存在可跳过；离线用 npm ci --offline
npm test                   # 本机实测 31 passed
node build.mjs             # 或 npm run build → dist/{bundle.js, styles.css, index.html}
```

注意：`dist/` 是跟踪文件，改完前端必须重建并确认 `git status` 无意外漂移（如 `package-lock.json` 被改动应还原）。

## 5. 启动与冒烟验证

```bash
cd desktop/backend
uv run short-lab --no-open          # 仅服务不弹浏览器；默认 127.0.0.1:46408
# uv run short-lab --port 45477     # 换端口（4万~6万区间内自选）
# uv run dive-desktop                # 旧命令，同一入口，仍可用
```

另开终端验证（本机实测输出）：

```bash
curl -s http://127.0.0.1:46408/api/health
# {"ok":true,"service":"dive-into-crypto-desktop","product":"short-lab","version":"0.3.0","ui_built":true}

curl -s http://127.0.0.1:46408/api/short/health
# {"ok":true,"available":true,"analysisTier":"LITE","scoreVersion":"ltss-lite-v1",...}

curl -s "http://127.0.0.1:46408/api/universe?limit=3"   # 应返回真实 BTC/ETH/SOL 行情
curl -s http://127.0.0.1:46408/ -o /dev/null -w "UI %{http_code}\n"   # 200
```

浏览器打开 `http://127.0.0.1:46408/`，界面默认中文，导航出现 SHORT LAB 即可。

> `GET /api/short/candidates` 在首次刷新前返回
> `{"error":"short_generation_not_found","detail":"no completed score_refresh generation"}`——**正常**，表示尚未跑过评分轮次（见下）。

### Short-Lab 首次数据回填（可选）

Short Lab 页点“刷新”或调 `POST /api/short/refresh` 后，后台开始全市场回填：funding 历史按 80 次/5 分钟限流，500 币约需 30–35 分钟（不含重试）。开发联调建议用小参数先验证链路，不必等全量。

## 6. 环境变量（开发常用）

| 变量 | 作用 | 默认 |
|---|---|---|
| `SHORTLAB_CONFIG_PATH` | 覆盖默认评分配置 | 包内 `shortlab/default.yaml` |
| `SHORTLAB_DATA_DIR` | DuckDB 写目录 | 源码态 `desktop/backend/runtime/`（git 忽略） |
| `DIVE_COINGECKO_API_KEY` | CoinGecko key（V1 公共端点可无） | 空 |
| `DIVE_FAPI_BASE` | 期货接口 host（用于镜像/代理） | `https://fapi.binance.com` |
| `DIVE_SPOT_BASE` | 现货接口 host | `https://api.binance.com` |

API Key 只走环境变量，绝不进仓库、日志、接口返回和前端 storage。

## 7. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `uv sync` TLS handshake 失败 | PyPI 直连被阻断；`uv sync --offline` 或直接用 `.venv` |
| `uv run` 报 resolvesplit 错误 | 离线无法重解析锁文件；改用 `.venv/bin/python -m pytest` |
| UI `Cannot find package 'esbuild'` | `node_modules` 缺失；`npm install`（离线 `npm ci --offline`） |
| 页面全屏“数据源不可用”+ 451 | Binance 地域限制；换可达网络，与代码无关 |
| `/api/short/candidates` 报 no generation | 未跑过 refresh；属正常初始态 |
| 端口被占用 | 换 `--port`（须在 40000~60000 区间内自选），或杀掉旧进程 |
| 界面是旧文案 | 改完前端忘 `node build.mjs`；`dist/` 需重建 |
