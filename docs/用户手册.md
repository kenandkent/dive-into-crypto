# 用户手册（Depth Terminal · short-lab）

> 研究分析工具，**非投资建议，不下单**。界面默认中文（设置 → 语言可切土耳其语/英语）。
> 说明：导航栏与 Short Lab 已全中文；个别视图内的旧标签仍为原文，将后续汉化，不影响操作。

## 0. 启动与通用操作

1. 启动后端（见《本地开发环境部署》或解压分发版运行 `short-lab`），浏览器打开 `http://127.0.0.1:46408/`。
2. 左侧图标栏切换页面；也可用地址 hash 直达：`#/scan`、`#/panel`、`#/shortlab`、`#/evidence` ……
3. 顶部状态条：实时连接点、指标数、周期；搜索框输入币种（如 SOL）定位。
4. `Ctrl+K` 打开命令面板：可跳视图（“SHORT LAB · 做空扫描”）、切主题、切语言（如“语言：中文”）、`kıyas BTC ETH` 式直达对比。
5. 数字键 `1–8` 快速切换前 8 个视图。
6. 设置页可换 4 套主题（Phosphor / Amber / Ice / Paper）与语言，实时生效。
7. 若顶部出现 DEMO 横幅，表示当前是离线演示数据（手动模式），非真实行情。

## 1. 扫描（市场扫描）

1. 进“扫描”页，设全市场范围与深度参数。
2. 点“深度扫描”：任务转后台，可在进度面板看进度，也可继续看别的页面。
3. 结果表看结论/置信度/评分三列 + 12 周期热力条；点任意行进入该币种面板。
4. 常用参数可存为“预设”（保存/重命名），预设支持导出/导入 JSON。
5. “对比”按钮把选中币种送去对比页。

## 2. 面板（币种深度）

1. 顶部搜索框输入币种（如 `BTC`），进入其面板。
2. 先看共识结论与置信度、风险等级。
3. 12 周期热力条判断多周期方向是否一致。
4. 指标表看 60 个指标各自信号；期货微结构 / 机制与汇流两块看衍生品与机制加分项；鲸鱼背离看大户持仓与价格是否背离。

## 3. OI·L/S（持仓与微结构）

1. 在面板或榜单选定币种后进入，页面展示该币种 5 分钟×48 根窗口的衍生品状态。
2. 微结构信号：看激活数（如 `5/6 信号有数据`）与总标签；逐条看 OI/价格背离、资金费、taker 攻击性等子信号。
3. 持仓与费率：OI（合约张数）、OI 变化、最新/平均资金费率、taker 买卖比（1.0 为均衡）。
4. 多空比：散户、顶部交易者持仓/账户四组（>1 偏多，<1 偏空；拥挤方向反读）。
5. 右侧榜单点击可切换币种。

## 4. 信号（短名单）

1. 直接看扫描幸存者的卡片墙：排名、价格、涨跌、置信度条、12 周期热力、鲸鱼标签、风险标签。
2. 点任意卡片进入该币种面板。
3. 若为空（尚未扫描），点“运行扫描”按钮。

## 5. 证据（引擎自评）

1. 选期限（1h / 4h / 24h）与窗口（7天 / 30天 / 全部）。
2. 点“立即评分”生成最新 graded 结果；数字含义：命中率卡（Wilson 区间，样本 <20 标门控）、可靠性图、ECE/Brier 徽标、基线对比、切片、重放网格。
3. “权重建议”仅报告、永不自动改引擎参数。
4. 可注册 claim（主张登记）跟踪后续验证。

## 6. SHORT LAB（做空研究，核心页）

### 6.1  scanner 列表

1. 先看顶部状态行：`LITE` 还是 `FULL`、分数版本、当前 generation。
2. 筛选（全部直传后端，支持组合）：
   - 状态 / 执行状态 / 画像（MEME_LITE 等）/ 分类（如 MEME）；
   - LTSS 最小值、Entry 最小值（0–100）；
   - 最小资金费 `%`（输入百分数如 `0.5`，即 0.5%）；
   - ATH 回撤区间（如 `-70` 到 `-40`，表示 -70%…-40%）；
   - 数据质量最小值。
3. 排序：不选即服务端默认序（READY > CANDIDATE > WATCH > PAUSED > BLOCKED > EXCLUDED，同状态按 LTSS/Entry/质量）；点表头按列排，null 永远沉底。
4. 分页固定 generation：翻页不漂移（第二页沿用同一 generationId）。
5. 点“刷新”提交后台评分任务；若已有同类任务在跑，会复用它（显示 existing）。
6. 点任意行进入详情。

### 6.2 状态速查

| 状态 | 含义 | 动作 |
|---|---|---|
| READY（·LITE / FULL） | 长期值得空 + 当前可入场 + 数据齐 | 重点研究对象，仍需自定仓位 |
| CANDIDATE | 长期值得空，当前不急入场 | 观察等入场信号 |
| WATCH | 有苗头，未达候选线 | 观察 |
| PAUSED | 长期逻辑可能成立但当前禁入场（暴涨/逼空/负费率/新币/事件） | 不入场，看原因 |
| BLOCKED | 禁止作为可执行候选（身份不明/数据太差/流动性不足/退市） | 不碰 |
| EXCLUDED | LTSS 不足 | 忽略 |

行内原因码（英文原码 + 中文解释）与 WARN 同时展示；WARN 只提示不改状态。

### 6.3 详情页（8 个区块）

1. 头部：画像、层级、分数版本、as-of 时间、generation；STALE 徽标表示快照已过期（只读降级，不重算）。
2. Summary：LTSS / Entry / 数据质量（含快照时刻值）/ 双状态。
3. Structure：ATH 回撤与币龄、30D 走势、均线、lower-high、现货量衰退。
4. Carry：7/30/90D 资金费、费率 APR（历史简单年化）、正费率占比、OI/市值、期现量比。
5. Valuation：市值、FDV、FDV/市值、流通比；不可用显示 N/A。
6. Tokenomics · Narrative：Phase 5 数据（解锁/社交）LITE 下为诚实占位，不编数字。
7. Existing Dive：引用现有引擎的结论/置信度/MTF/微结构/机制/鲸鱼（只读引用）。
8. Risks：BLOCK/PAUSE/WARN 原码 + 中文解释。
9. Data Sources：每个来源的新鲜度/状态/原因——STALE 行的字段级原因在这里查。

### 6.5 对冲研究（Hedge，默认关闭，需启用）

1. 需后端配置开启 `hedge.enabled` 才会出现 planner/monitor/alerts 与 funding 入口；默认关闭时相关接口返回不可用，这是正常状态。
2. 先看 funding 机会与三场所比价：同一金额下 `BINANCE_SPOT` / `BINANCE_ALPHA` / `ONCHAIN_DEX` 并排展示；未配置的场所显示不可用原因（如 `CHAIN_PROVIDER_UNCONFIGURED`），不等同于“报价为零”。
3. `模拟`只生成参考参数（60 秒有效期），点“登记计划”转为本地计划；所有数量/金额均为文本数字，冲突或过期会明确报错（409）。
4. **唯一的成交记录方式是手工录入**：在计划 legs 页按实际成交逐笔登记（`USER_ENTERED`）；“激活/关闭”只改本地计划状态，不下单、不同步平仓。
5. monitor 页看比例/敞口/资金费/基差/强平距离快照；alert 需逐条 ack，ack 只表示“已读”，不表示问题已解决。
6. 场所现状：Binance Spot 默认可用；Binance Alpha 默认关闭；链上（0x）需另配 Key，无 Key 时保持未配置状态。

### 6.6 缺失值读法

- `—`：暂无数据；`N/A`：已确认不存在（如无现货市场）；`UNAVAILABLE`：临时不可用；三者绝不写成 0。
- `entryScore` 为 null + “未计算”：Entry 缺必需输入，不是 0 分。

## 7. 对比

1. 添加 2–4 个币种（页面添加框，或命令面板 `kıyas BTC ETH SOL`）。
2. 图表共享时间轴、从右端对齐，适合看相对强弱与分化。
3. 点币种可跳其面板。

## 8. 热力图

1. 切换“扫描”（本次扫描幸存）/“全市场”两种模式。
2. 颜色=结论方向，浓度=置信度；轮廓线为相关性聚类。
3. 找同跌/同涨的板块性机会与异动个币。

## 9. 组合（本地账本）

1. “添加持仓”：币种、方向（多/空）、入场价、数量；数据只存本机，不连交易所。
2. 列表看现价、盈亏 %（实时计价）、结论；可编辑/删除。
3. 缺现价的行不计入 totals，如实标注排除。

## 10. 结构

1. 看 BTC Beta / 相关性聚类：验证徽标表示指数候选已确认名称。
2. “未聚类”尾巴列出不属于任何簇的币种；退市/不可用币种只具名、不编数。

## 11. 日志

查看最近请求的真实网络日志（方法、状态码、耗时），排查“是不是数据源问题”的第一站。

## 12. 设置

1. 外观：4 套主题即时切换。
2. 语言：中文 / TR / EN，切换即时生效并记住选择。
3. 引擎：查看 60 指标 + 3 叠加的说明（只读）。

## 13. 常见问题

- **全屏“数据源不可用”+ 451**：Binance 在你所在地区受限，换网络，与软件无关。
- **扫描/币种报错**：同上多为网络； Short Lab 的 STALE/UNAVAILABLE 按 6.6 读。
- **Short Lab 列表为空**：还没跑过刷新任务，点“刷新”并等待回填（全市场约半小时）。
- **READY 也会亏**：READY 是“可研究”，不是交易信号；务必自定仓位与止损。
- **对冲页显示不可用**：多为 hedge 未启用或 Alpha/0x 未配置（无 Key 即记未配置，不视为已验证可用）；先确认后端配置与 Key，再看接口返回的原因码。
- **本工具不自动交易**：所有计划与 monitor 均为参考与手工台账；不承诺无损、不承诺强平保护已验证，强平距离仅为参考计算。
